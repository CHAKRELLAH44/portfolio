## Under the hood

- **Front end:** hand-written HTML, CSS and vanilla JavaScript. No framework, no build step.
- **Back end:** [Supabase](https://supabase.com/) (Postgres + REST + Auth) with row-level security. Visitors can only add, never read or change.
- **Testimonials:** submitted on the site, moderated before they appear, with an email alert for each new one.
- **Analytics:** a small home-made tracker. No cookies, no IP addresses, no persistent visitor ID, and *Do Not Track* is respected.
- **Hosting:** GitHub Pages, plus a scheduled GitHub Action that keeps the free database awake.
- **Libraries:** none. Scroll reveal and icons are built in (glyphs from [Boxicons](https://boxicons.com/), MIT); fonts (Archivo, Instrument Sans, IBM Plex Mono) are served from the site, so there is no request to Google.

```
├── index.html · projects.html · contact.html · hidden-me.html · 404.html · admin.html
├── css/
│   ├── base.css         # page-wide rules: reset, colours (+ light theme), container, cursor, toast, touch
│   ├── fonts.css        # @font-face for the self-hosted fonts (generated by tools/fetch_fonts.py)
│   ├── reveal.css       # scroll reveal (data-aos), icons.css = inline SVG icon sizing, titles.css = section titles
│   ├── header.css · hero.css · about.css · experience.css · skills.css
│   ├── testimonials.css · contact.css · footer.css      # one file per element of the home page
│   ├── projects.css · hidden-me.css                     # one file per page
│   └── 404.css · admin.css
├── js/
│   ├── core.js          # every page: scroll reveal, icons, theme, navigation, toast, contact form, share
│   ├── home.js          # home page: hero, stats, skills, timeline, testimonials
│   ├── projects.js      # projects page: project modal, filters, course carousel
│   ├── hidden-me.js     # Hidden Me page: chapters, F1 game, Penalty Lab
│   ├── 404.js           # terminal 404 page
│   ├── i18n.js          # English in the HTML, French dictionary here
│   ├── analytics.js     # anonymous visit tracking
│   ├── supabase-config.js  # public project URL + publishable key
│   └── admin/           # moderation dashboard
├── supabase/            # SQL: tables and security policies
├── tools/check.py       # static checks: missing files, unreferenced assets, icon sprites, one h1 and one main per page
├── tools/build_icons.py # builds each page's inline icon sprite from tools/icons (sources in tools/icons/README.md)
├── tools/fetch_fonts.py # downloads the fonts into assets/fonts and writes css/fonts.css
├── site.webmanifest · robots.txt · sitemap.xml
└── assets/
    ├── brand/           # logo, favicons, social cover
    ├── profile/         # optional: photo.webp or photo.jpg replaces the About placeholder
    ├── projects/        # screenshots, one folder per project; tiles/ = placeholder thumbnails
    ├── hidden-me/       # photos for the personal page
    ├── fonts/           # WOFF2 files (Archivo, Instrument Sans, IBM Plex Mono)

```

Load order on a page: `base.css`, then the partials the page needs; `i18n.js`, `supabase-config.js`, `core.js`, then the page's own script.
Run `python tools/check.py` before committing.

## Add your photo

The About section shows an "IMANSKA" placeholder card. To show a real photo instead, save it as
`assets/profile/photo.webp` (or `photo.jpg`) and reload. No code change is needed. A portrait shape works
best (about 4 wide by 5 high, 1000 pixels wide is plenty). Until the file exists the browser tools list a
harmless 404 for it; that is the page looking for the photo.

## Run it locally

No install needed. Clone the repo and open `index.html`, or serve the folder:

```bash
git clone https://github.com/CHAKRELLAH44/portfolio.git
cd portfolio
npx serve .
```

Visits from `localhost` and `file://` are never counted.

<details>
<summary><b>Using this as a template?</b></summary>

1. Create a free Supabase project.
2. Run `supabase/testimonials.sql`, then `supabase/admin.sql`, then `supabase/analytics.sql` in the SQL Editor.
3. Put your project URL and publishable key in `supabase-config.js` and `.github/workflows/supabase-keepalive.yml`.
4. Replace the content, the images and the CV with your own. Please don't ship mine.

</details>
